## Daftar Temuan Bernomor (Findings List)

### 1. [R-32] Modal Profil dan Dialog Logout Tidak Memiliki Listener Tombol `Escape`
- **Tingkat Prioritas:** HIGH (Hard Gate)
- **Lokasi:**  
  - `src/features/customer/components/CustomerProfileModal.jsx` (baris 27-63)  
  - `src/features/customer/components/CustomerSidebar.jsx` (baris 216-258: modal konfirmasi logout)
- **Alasan:** Kedua dialog modal ini diimplementasikan secara terpisah tanpa komponen `BaseModal` dan tidak mendengarkan event keyboard `Escape` untuk menutup dialog secara aksesibel.

### 2. [R-02 / Craftsmanship] Integritas Teks Terganggu oleh Karakter Rusak (Mangled UTF-8 Encoding)
- **Tingkat Prioritas:** HIGH (Hard Gate)
- **Lokasi:**  
  - `src/features/customer/components/TicketTimelineModal.jsx` (baris 27, 66, 99: karakter bullet `â€¢`)  
  - `src/features/customer/views/MyTickets.jsx` (baris 144: `â€¢ Sesuai Jadwal`)  
  - `src/features/customer/views/MyTickets.jsx` (baris 472, 524, 561, 638: marker Leaflet berisi broken emoji `ðŸš—`, `ðŸ“?`, `ðŸ??`)
- **Alasan:** Terdapat teks antarmuka dan penanda rute yang mengandung karakter simbol dan emoji rusak (*corrupted byte sequence*) yang merusak profesionalisme dan kenyamanan membaca pengguna.

### 3. [R-32 & R-39] Hilangnya Indikator Fokus Keyboard (`focus-visible`) & Atribut ARIA Pilihan Layanan
- **Tingkat Prioritas:** HIGH (Hard Gate)
- **Lokasi:**  
  - `src/features/customer/components/CustomerSidebar.jsx` (baris 163-197: tombol navigasi menu)  
  - `src/features/customer/views/SearchTrip.jsx` (baris 555-573: tombol pilihan tipe layanan "Nebeng Motor", "Nebeng Mobil", "Nebeng Barang")
- **Alasan:** Elemen menu navigasi dan tombol pemilihan layanan tidak memiliki ring fokus visual saat dijelajahi dengan tombol `Tab`, serta tombol layanan tidak memiliki atribut semantik `role="tab"` atau `aria-pressed` untuk pembaca layar.

### 4. [R-03] Ukuran Target Sentuh (Tap Target) Tombol di Bawah 44px pada Mobile
- **Tingkat Prioritas:** HIGH (Hard Gate)
- **Lokasi:**  
  - `src/features/customer/views/CustomerWallet.jsx` (baris 984, 992: tombol filter riwayat dan tombol nominal cepat `px-2 py-0.5`, tinggi hanya ~22px)  
  - `src/features/customer/views/SearchTrip.jsx` (baris 1020, 1171: tombol aksi mikro pada dialog rincian tiket `py-1.5 px-3`, ~28px)
- **Alasan:** Target sentuh elemen kontrol interaktif berada jauh di bawah standar ergonomi minimum layar sentuh (44x44px), memperbesar risiko salah sentuh pada pengguna ponsel.

### 5. [R-25] Kontras Warna Teks Kategori dan Status di Bawah Standar WCAG AA
- **Tingkat Prioritas:** MEDIUM (Purpose-Gate)
- **Lokasi:**  
  - `src/features/customer/components/CustomerSidebar.jsx` (baris 155: `text-blue-200/60` dan baris 142: `text-white/50` di atas latar navy)  
  - `src/features/customer/views/CustomerWallet.jsx` (baris 421: `text-neutral-400` di atas latar putih terang)
- **Alasan:** Rasio kontras teks keterangan dan judul grup menu berada di kisaran 2.6:1 hingga 3.2:1 (gagal memenuhi rasio minimum 4.5:1 WCAG AA untuk teks berukuran kecil).

### 6. [R-04] Penggunaan Ikon Generik `Sparkles` pada Berbagai Fungsi yang Tidak Relevan
- **Tingkat Prioritas:** MEDIUM (Purpose-Gate)
- **Lokasi:**  
  - `src/features/customer/views/MyTickets.jsx` (baris 964: tombol refresh tiket memakai ikon `Sparkles animate-spin`, serta baris 1178 pada kartu poin loyalty)  
  - `src/features/customer/views/CustomerWallet.jsx` (baris 418: badge NEBENG PAY)  
  - `src/features/customer/views/CustomerRewards.jsx` (baris 281) & `CustomerVouchers.jsx` (baris 190, 267)  
  - `src/features/customer/views/CustomerAccountSettings.jsx` (baris 20: impor mati / dead import `Sparkles`)
- **Alasan:** Ikon *sparkle* dipakai sebagai pola default AI di berbagai tempat (termasuk tombol refresh dan badge dompet) alih-alih menggunakan ikon yang relevan secara fungsional seperti `RefreshCw`, `Coins`, atau `ShieldCheck`.

### 7. [R-01 & R-13] Efek Ambient Glow Orbs & Skeuomorfisme Chip Kartu Palsu
- **Tingkat Prioritas:** MEDIUM (Purpose-Gate)
- **Lokasi:**  
  - `src/features/customer/views/CustomerWallet.jsx` (baris 444-445: lingkaran blur dekoratif besar `blur-3xl`, dan baris 450-452: ornamen chip kartu debit/kredit palsu gradasi kuning emas)  
  - `src/features/customer/views/SearchTrip.jsx` (baris 539-540: ornamen lingkaran blur pada banner)
- **Alasan:** Penggunaan chip kartu kredit buatan dan lingkaran cahaya kabur (*ambient glow orbs*) merupakan pola visual generik tanpa fungsi nyata dalam sistem dompet digital aplikasi.

### 8. [R-08] Penggunaan Ikon Panah (`ArrowRight`) pada Tombol Aksi Tanpa Alasan Fungsional
- **Tingkat Prioritas:** MEDIUM (Purpose-Gate)
- **Lokasi:** `src/features/customer/views/SearchTrip.jsx` (baris 806)
- **Alasan:** Tombol "Pesan Sekarang" menyertakan ikon panah `ArrowRight` dekoratif secara default, padahal aksi tombol sudah jelas secara teks.

### 9. [R-33] Manipulasi Gaya DOM Secara Imperatif (*Imperative DOM Style Patching*)
- **Tingkat Prioritas:** MEDIUM (Purpose-Gate)
- **Lokasi:**  
  - `src/features/customer/views/SearchTrip.jsx` (baris 802-803: manipulasi `e.currentTarget.style.backgroundColor` pada hover)  
  - `src/features/customer/views/BiometricOnboarding.jsx` (baris 465, 483, 498, 514: manipulasi `borderColor` pada `onBlur`)  
  - `src/features/customer/views/CustomerAccountSettings.jsx` (baris 501, 550, 614, 643: manipulasi `borderColor` pada `onBlur`)  
  - `src/features/customer/views/CustomerChat.jsx` (baris 278, 533)
- **Alasan:** Memanipulasi properti CSS DOM langsung melalui event handler JavaScript daripada menggunakan kelas utilitas deklaratif Tailwind CSS (`focus:border-brand-500 hover:bg-brand-700`).
